# Mumbai Heritage Inn - Local 4-Star Hotel Website

A warm, cozy, and practical single-page hotel website for a local 4-star hotel in Mumbai.

## Tech Stack
- Pure Semantic HTML5 & CSS3
- Vanilla JavaScript
- Inline SVG icons (crisp, scalable, dependency-free)
- Google Fonts: Playfair Display & Poppins
- Intersection Observer for scroll-reveal animations
- Dynamic WhatsApp Form integration

## Design System
- Background: `#faf6f0` (warm white)
- Surface/Cards: `#f0e9de` (beige)
- Accent: `#8b5e3c` (warm brown)
- Accent 2: `#c9973a` (muted gold)
- Text Primary: `#2c1f14` (dark brown)
- Text Muted: `#7a6a5a` (warm grey-brown)
- Border: `#ddd0be`
